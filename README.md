# Scrub My Data (free Claude skill)

Get your name, address and phone number off people-search sites without paying a removal
service. Removal services charge from about $39 to $250 a year. This costs $0 in fees.

## How to use it (one step)

Open Claude Code and paste this:

    Install the scrub-my-data skill from https://github.com/mattiklodi/scrub-my-data and remove my data from people-search sites.

Claude will explain what it does, ask before downloading anything, then ask you a few
questions one at a time (your name, your state, the email to file from).

## What to expect

- It files the opt-out requests from your own email and keeps a log on your computer.
- You'll still click some confirmation emails and maybe solve a captcha.
- Sites can relist you, so it offers to re-check every month.
- Not legal advice.
